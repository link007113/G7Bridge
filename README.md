# G7 Bridge

Use a GameSir G7 Pro over its 2.4 GHz receiver as a virtual Steam Controller, including independent extra buttons and gyro.

- [Download the Windows installer](https://github.com/link007113/G7Bridge/releases)
- [Source and installation guide](https://github.com/link007113/G7Bridge/tree/feature/installer-localization)

The first installer is published as a preview while manual installation acceptance and independent review are pending. The source, English/Dutch documentation and build scripts are in the linked feature branch and draft pull request.

Windows 11 24H2 or later, x64. An independent community project, unaffiliated with GameSir or Valve.
